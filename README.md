# SmartMeet AI

A modern, AI-powered meeting intelligence platform built with Vue 3, TailwindCSS, and Phosphor Icons.

## Tech Stack

- **Vue 3** — Composition API + `<script setup>`
- **Vite 5** — Lightning-fast dev server and bundler
- **TailwindCSS v3** — Utility-first CSS with custom DealDeck glassmorphism design tokens
- **Phosphor Icons** — Consistent vector icon system (`@phosphor-icons/vue`)

## Features

- 🏠 **Landing Page** — Hero, Bento feature grid, Workflow steps, Integrations, Testimonials, CTA
- 🔐 **Auth Pages** — Sign In and Sign Up with glassmorphic card forms and SSO buttons
- 📊 **Dashboard** — Full sidebar nav, meeting cards, AI insights panel, activity chart, task checklist
- 💎 **Light-Mode Glassmorphism** — Frosted glass cards, aurora backdrop orbs, animated gradients
- ✨ **Smooth Page Transitions** — Fade + slide transitions with auto scroll-to-top

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## Deployment

Deployed on **Vercel**: [smartmeet-ai-smoky.vercel.app](https://smartmeet-ai-smoky.vercel.app)

To redeploy:
```bash
npx vercel --prod
```
